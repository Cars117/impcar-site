Утилизационный сбор для легковых автомобилей (категория M1) рассчитывается по Постановлению Правительства РФ № 1291 в действующей редакции: базовая ставка — 20 000 ₽; льгота для физлиц на личное пользование — коэффициенты 0,17 (до 3 лет) и 0,26 (старше 3 лет). 30‑минутная мощность принимается по данным ОТТС / СБКТС / ЭПТС. Для автомобилей, ввозимых не для личного пользования, применяются повышающие коэффициенты. При расхождении заявленной и таможенной стоимости таможенный орган вправе пересчитать пошлины, НДС, акциз и утилизационный сбор по собственной оценке; итоговые суммы фиксируются в решении таможенного органа. Точные действующие ставки и коэффициенты уточняйте у вашего таможенного представителя.
